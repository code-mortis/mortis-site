The [Code Mortis App](https://github.com/code-mortis/code-mortis) v0.1.4 runs Mortis Engine 0.1.9 for AI analysis and its own Trivy integration for dependency, secret, and configuration checks. Reviews, findings, coverage, and model usage are saved on your instance. The AI provider you select receives eligible source and diffs during analysis.

## Find work in the workspace

Use the pull request inbox to search across repositories you can access. Open a repository’s **Overview** for its latest review, security snapshot, and activity calendar. The activity inbox lets you follow queued and running jobs while you work elsewhere.

<DocCapture image={overview} alt="The Ledger repository overview showing two open review findings, three open security findings, and the latest scan grade." />

Select a day in the activity calendar to see its review and scan counts.

<DocCapture image={activity} alt="The repository activity calendar showing five reviews and two security scans on the selected day." />

Open **Analytics** for a repository to filter reviews, findings, reported token usage, and security results by date, or download the figures as CSV. Administrators manage workspace members in Settings. GitHub installation access and repository permissions also determine which repositories each member can see and change.
