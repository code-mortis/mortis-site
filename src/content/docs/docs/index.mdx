## Preview your first review

From a Git repository with at least one commit and a local change, install the Engine and inspect the files it would review. The preview runs on your machine and needs no API key.

```sh title="Terminal"
uv tool install mortis-engine
mortis review --preview
```

## Work with your coding agent

For local changes, [install the Engine skill](/docs/engine/cli/#use-with-coding-agents) to give your agent the CLI workflow. On a GitHub pull request, [ask the Action a question](/docs/action/pull-requests/#review-and-discuss-a-pull-request) about the current diff. To investigate a saved App finding, [connect your agent through MCP](/docs/app/mcp-and-api/#connect-scripts-and-agents) and choose the repositories it can read.

The Engine keeps local history, the Action writes reports on its runner, and the App saves results on your instance. During analysis, eligible source and diffs go to the AI provider you configure. [Compare Code Mortis with other review tools](/comparison/).
