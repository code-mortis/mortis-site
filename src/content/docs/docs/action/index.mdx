[Mortis Review and Scan](https://github.com/marketplace/actions/mortis-review-and-scan) runs Mortis Engine in GitHub Actions. Use it for automatic PR reviews, manual review commands, or comparisons between two Git refs. See the [scan compatibility note](/docs/action/ci/#scan-mode-in-v020) before configuring a security job. [Mortis Action v0.2.0](https://github.com/code-mortis/mortis-action/releases/tag/v0.2.0) installs Mortis Engine 0.1.5 on a Linux runner. The Engine sends eligible source and diffs to your configured AI provider.
