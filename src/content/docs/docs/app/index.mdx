The [Code Mortis App](https://github.com/code-mortis/code-mortis) runs Mortis Engine 0.1.5 for AI analysis and its own Trivy integration for dependency, secret, and configuration checks. Reviews, findings, coverage, and model usage are saved on your instance. The AI provider you select receives eligible source and diffs during analysis.

## Find work in the workspace

Use the pull request inbox to search across repositories you can access. Open a repository’s **Overview** for its latest review, security snapshot, and activity calendar. The activity inbox lets you follow queued and running jobs while you work elsewhere.

Open **Analytics** for a repository to filter reviews, findings, reported token usage, and security results by date, or download the figures as CSV. Administrators manage workspace members in Settings. GitHub installation access and repository permissions also determine which repositories each member can see and change.
