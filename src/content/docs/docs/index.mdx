Mortis Engine reviews Git changes, checks findings against specific revisions, and scans repository security. Choose the guide for how you want to run it.

## Python library

Embed Mortis in a Python project. Preview the files a review would cover, run the review with your application's credentials, and read findings and coverage from the returned dictionary. [Use the Python library](/docs/library/)

## Command-line interface

Review staged changes before a commit or compare a branch with its base. Save a provider connection, follow progress in the terminal, and export results as Markdown or JSON. [Use the CLI](/docs/cli/), [review subsequent commits](/docs/cli/#review-subsequent-commits), or [install the coding-agent skill](/docs/cli/#use-with-coding-agents).

Both interfaces operate on a local Git repository. Previews run offline. During analysis, Mortis sends eligible source and diffs to the AI connection you select and saves run history locally.

[Compare Code Mortis with PR-Agent, Kodus, OCR, and Qodo](/comparison/) to see how each tool handles review and follow-up.
