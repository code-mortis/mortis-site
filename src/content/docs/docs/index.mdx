Mortis Engine reviews Git changes, checks findings against specific revisions, and scans repository security. Choose how you want to run Mortis.

## Python library

Embed Mortis in a Python project. Preview the files a review would cover, run the review with your application's credentials, and read findings and coverage from the returned dictionary. [Use the Python library](/docs/library/)

## Command-line interface

Review staged changes before a commit or compare a branch with its base. Save a provider connection, follow progress in the terminal, and export results as Markdown or JSON. [Use the CLI](/docs/cli/), [ask about or describe the changes](/docs/cli/#ask-about-or-describe-a-branch-comparison), [review subsequent commits](/docs/cli/#review-subsequent-commits), or [install the coding-agent skill](/docs/cli/#use-with-coding-agents).

The CLI and Python library operate on a local Git repository. Previews run offline. During analysis, Mortis sends eligible source and diffs to the AI connection you select and saves run history locally.

[Compare Code Mortis with other review tools](/comparison/) to see how each tool handles review and follow-up.

## GitHub Action

Review pull requests as commits arrive, reuse coverage on subsequent pushes, compare branches, and scan revisions in CI. [Set up Mortis Action](/docs/github-action/)

## Code Mortis App

Self-host a web workspace for GitHub pull request reviews, security scans, and code navigation. Run reviews automatically or on demand, track findings and coverage, and connect your own AI provider. [Set up the Code Mortis App](/docs/app/)
